# Question 15 - Discrete-Time Fourier Transform (DTFT)

## Category
Theory

## Topic
Discrete-Time Fourier Transform (DTFT)

## Question
Which of the following correctly describes the **Discrete Time Fourier Transform (DTFT)**?

## Options
A. Converts a **sampled sequence** into a **continuous function of normalised frequency**

B. Converts a **continuous analogue signal** into a **sampled function of frequency**

C. Converts a **sampled sequence** into a **sampled function of normalised frequency**

D. Converts a **sampled sequence** into a **continuous function of frequency**

## Correct Answer
**A**

## Explanation
The DTFT takes a discrete-time sequence, such as \(x[n]\), and represents it as \(X(e^{j\Omega})\), which is a continuous function of normalised angular frequency \(\Omega\). The frequency variable is normalised because it is measured in radians/sample rather than in continuous-time units such as radians/second.

Option C describes the DFT more closely, because the DFT gives sampled frequency-domain values. Option D is close, but it misses the key word **normalised**.

## Must-know concept
DTFT: discrete in time, continuous in normalised frequency.  
DFT: discrete in time, sampled/discrete in frequency.
