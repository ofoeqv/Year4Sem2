# Question 7 - Discrete Fourier Transform (DFT)

## Category
Theory

## Topic
Discrete Fourier Transform (DFT)

## Question
Which of the following correctly describes the **Discrete Fourier Transform (DFT)**?

## Options
A. Converts a **sampled sequence** into a **continuous function of normalised frequency**

B. Converts a **continuous** analogue signal into a **sampled** function of frequency

C. Converts a **sampled sequence** into a **sampled function of normalised frequency**

D. Converts a **sampled sequence** into a **continuous function of frequency**

## Correct Answer
**C. Converts a sampled sequence into a sampled function of normalised frequency.**

## Explanation
The DFT takes a finite-length discrete-time sequence, such as \(x[n]\), and produces a discrete set of frequency-domain samples, usually written as \(X[k]\). These frequency samples correspond to equally spaced samples of the DTFT over normalised frequency.

So the key idea is:

\[
\text{DFT: sampled/discrete in time} \rightarrow \text{sampled/discrete in normalised frequency}
\]

Option A describes the DTFT more closely, because the DTFT produces a continuous function of normalised frequency.

## Must-know concept
DTFT: discrete-time sequence \(x[n]\) to continuous normalised-frequency function \(X(e^{j\Omega})\).  
DFT: finite discrete-time sequence \(x[n]\) to sampled/discrete normalised-frequency values \(X[k]\).
