# Quiz 3 Question 9

## Question
For a moderately doped Si pn junction, the dominant recombination process is:

A. Shockley Read Hall (SRH)
B. Auger
C. Radiation
D. Impact ionisation

## Answer
A. Shockley Read Hall (SRH)

## Feedback
Tunnelling is not a carrier recombination process.

Impact ionisation is not a carrier recombination process.

Radiative recombination is not dominant because Si is an indirect bandgap semiconductor.
