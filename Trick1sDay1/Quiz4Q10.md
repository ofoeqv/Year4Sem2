# Quiz 4 Question 10

## Question
Which of the following combinations, arranged in the correct order from the top to the bottom junctions, can be used in a 3-junction tandem solar cell?

A. In0.49Ga0.51P / GaAs / Ge
B. Al0.1Ga0.9As / InAs / GaAs
C. GaAs / Ge / Al0.3Ga0.7As
D. GaAs / In0.53Ga0.47As / GaP

## Answer
A. In0.49Ga0.51P / GaAs / Ge

## Feedback
This is the correct top-to-bottom junction order for a 3-junction tandem solar cell.

The top junction needs the largest bandgap, the middle junction uses an intermediate bandgap, and the bottom junction uses the smallest bandgap.
